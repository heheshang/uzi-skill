## 席位匹配技巧

```rust
use uzi_investors::seat_db::{is_in_range, match_seats_in_lhb};

let matched = match_seats_in_lhb(&lhb_records);
// matched = {"章盟主": [{...}, {...}], "佛山无影脚": [{...}]}

if let Some(obj) = matched.as_object() {
    for nick in obj.keys() {
        if is_in_range(nick, &ticker_features) {
            println!("{nick} 在射程内，是真实信号");
        } else {
            println!("{nick} 不在风格里，可能只是路过");
        }
    }
}
```

> `match_seats_in_lhb` 把每条龙虎榜记录的字段值拼成文本，与每个席位的 `seats` 别名做**子串包含**匹配
> （如 `"东方财富证券股份有限公司拉萨"` 前缀即可命中拉萨天团）；命中则收录该游资的原始记录。

## `is_in_range` —— 射程判定

`uzi_investors::seat_db` 的 `is_in_range(nickname, ticker_features)` 判断某游资**是否可能参与**这只票，规则按顺序：

1. `nickname` 不在 23 席位表内 → 直接 `false`
2. 有显式 `min_mcap` → 市值低于下限则 `false`
3. 有显式 `max_mcap` → 市值高于上限则 `false`
4. **无显式 `max_mcap`** 且不在白名单 → 市值高于隐含上界 **500 亿元**（`FALLBACK_YOUZI_MAX_MCAP_YUAN`）则 `false`
   - `章盟主` 在白名单（`MEGA_CAP_ALLOWLIST`）内，**不受**该上界约束（可参与超大盘）
5. 其余非 `min_` / `max_` 规则（如 `trend: "up"`、`is_sector_leader: true`）逐项与 `ticker_features` 相等比对

**v3.4.5 覆盖规则**：即使算出"不在射程"，只要 `16_lhb.data.matched_youzi` 里命中了该席位，仍**强制参与评分** —— 真实成交记录优先于静态射程假设（见 `uzi_investors::evaluator` 的 F 组射程前置检查）。
